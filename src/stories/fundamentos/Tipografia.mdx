# Tipografía

Tres voces, cada una con un trabajo. No son tres fuentes «para variar»: cada una
dice de qué clase es el texto que estás leyendo.

## Por qué la mono no es una fuente externa

Las otras dos se cargan; la mono usa la del sistema a propósito. Un teléfono, una
hora o un conteo tienen que salir alineados y legibles **aunque la fuente no haya
cargado todavía** — y son justo los datos que se leen de un vistazo mientras se
trabaja.

## Tabular

Las cifras que se comparan entre filas van con `tabular-nums`: sin eso, los números
bailan de columna en columna y una lista de conteos deja de poder leerse en vertical.
