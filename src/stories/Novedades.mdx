# Novedades

Este Storybook se sincroniza con el frontend real de Hermes (`Goberna-Lab/hermes`,
rama `main`). Cuando eso trae componentes nuevos o cambiados, queda un registro
acá abajo — así que basta con abrir esta página al entrar para saber qué cambió.

**"Sincronizar ahora" revisa `hermes/main` y trae lo nuevo a este repo** — corre
en tu máquina, no toca nada del monorepo real (solo lee de ahí), y deja un commit
local listo para pushear cuando quieras. Solo funciona con `npm run storybook`
corriendo local.
