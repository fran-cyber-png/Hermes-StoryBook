# Novedades

Este Storybook se puede sincronizar con el frontend real de Hermes (`Goberna-Lab/hermes`,
rama `main`) — hoy es manual (con el botón de abajo, o pidiéndolo en una sesión de
Claude Code). Cuando trae componentes nuevos o cambiados, queda un registro acá abajo —
así que basta con abrir esta página al entrar para saber qué cambió.

**"Sincronizar ahora" revisa `hermes/main` y trae lo nuevo a este repo** — corre
en tu máquina, no toca nada del monorepo real (solo lee de ahí), corre `tsc`
para confirmar que nada se rompió, y deja un commit local listo para pushear
cuando quieras. Solo funciona con `npm run storybook` corriendo local.

Si `tsc` encuentra algo, **el commit se hace igual** — es preferible avisar de
una sincronización con un error de tipo que dejarla sin hacer y perder el aviso
de qué cambió en el monorepo real. El aviso queda arriba de todo, en rojo, con
la story exacta que hay que abrir.

Cada sincronización lista los archivos que tocó, con la ruta completa y qué le
pasó a cada uno — <strong>A</strong> nuevo, <strong>M</strong> modificado,
<strong>D</strong> borrado, <strong>R</strong> renombrado — y a la derecha, dónde
vive ese componente en este Storybook. Los que dicen «sin story» son los que
todavía nadie cubrió: esa columna es la lista de trabajo pendiente.
